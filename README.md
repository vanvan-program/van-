# van课表

原生 Android 本地课表应用。Kotlin / Compose / Room / DataStore，GPL-3.0-only。
目前仅支持Android端
仓库包含源码、构建配置、合成样例与脱敏验证资料。本机工具缓存、构建产物、个人课表原件和签名密钥不属于仓库内容。

## 已实现

- 课表／课程／我的三页导航，紧凑周网格与单行下一节提示，默认按屏幕高度适配整周，可切日列表。
- 全部自有页面双色主题、字号、行高、周末与非本周显示设置。
- 多课表一份启用；课程多时段、间断周、自定义钟点、单次课程与整周实践。
- 多作息日期规则、整日停课／替换、单次取消／移动／地点时间修改。
- WakeUp 五行备份、七列 CSV、本机备份解析及事务保存为新表；WakeUp 作息关联 ID 不一致时按文件内容重建关联。
- 完整备份恢复、覆盖前快照、单表数据与周图片分享。
- 原生滚动双日／今日小组件、下一节卡片、实例独立主题。
- 课前提醒、可选课程状态通知、授权检测、测试通知和手环镜像说明。
- 自行输入教务系统网址或选择文件；按页面路径选择通用或协议获取器，不内置真实学校名称和网址，默认清理登录会话。
- PDF、Excel（.xlsx/.xls）、课表图片本机导入；选择Excel工作表、逐页PDF识别、可编辑识别结果核对，确认后进入学期与作息预览。

```properties
storeFile=tr/van-original-debug.keystore
storePassword=填写原密钥密码
keyAlias=androiddebugkey
keyPassword=填写原私钥密码
```

配置存在时，Debug 和 Release 均使用该密钥，并在构建前核对原版证书 SHA-256
`2787e9a025cbd6606ac2ec05415432513ada6732360ce4dc2abb22e049e938bf`。

## 验证边界

0.1.3增加PDF、Excel和图片导入。Excel读取七列课程表和带星期表头的周网格；PDF由Android本机渲染后识别，图片采用随安装包提供的中英文离线OCR模型。识别可能出现错字、漏课或缺字段，保存前可修改、补充和移除课程，不会猜测缺失的星期、节次或学期周次。整周截图若只有日期而没有学期周次，需要用户补全。PDF最多12页，文件最多25MB（Excel20MB）。

## 构建

Java 21（产物 JVM 17）、Gradle 9.3.1、Android SDK 37.0、Build Tools 36.0.0。

在 Android Studio 打开此目录，设置本机 SDK；或配置 `local.properties` 后执行：

```powershell
.\gradlew.bat :core:domain:test :app:assembleDebug :app:lintDebug
.\gradlew.bat :app:connectedDebugAndroidTest
```

中文 Windows 路径可能导致 JVM 测试进程无法启动；本机开发使用临时目录路径别名，真实项目仍在原目录。工具缓存位于上级 `.tools`，不属于应用源码。

本机可直接运行 `./build-local.ps1`；其他 SDK / Java 路径通过 `-SdkPath`、`-JavaPath` 指定。使用说明和验证边界见 [使用与待验证项](docs/使用与待验证项.md)。

APK：`app/build/outputs/apk/debug/app-debug.apk`。这是本地调试签名包；正式签名与发布另行处理。

## 数据与权限

课程聚合保存于 Room，设备偏好使用 DataStore。没有分析、广告或第三方后台。文件、PDF及图片识别在本机进行，不上传课表文件或识别结果；识别模型随包提供，不需要登录识别服务。数据库不参与 Android 自动云备份。导出备份不包含登录 Cookie、账号密码、系统授权或小组件实例ID。

显式权限：INTERNET、POST_NOTIFICATIONS、SCHEDULE_EXACT_ALARM、RECEIVE_BOOT_COMPLETED。完整合并 Manifest 以构建报告为准。文件通过 SAF 与 FileProvider 使用，不需要广泛存储、相机、位置或蓝牙权限。
