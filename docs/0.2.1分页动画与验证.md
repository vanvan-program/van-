# van课表 0.2.1：课表分页动画

日期：2026-10-12。versionName=0.2.1，versionCode=14。

## 实现

参考 [ryanw-mobile/compose-pager-demo](https://github.com/ryanw-mobile/compose-pager-demo)
的分页偏移与绘制层动画方式，使用项目已有的 Compose Foundation `HorizontalPager`。
未增加第三方运行时依赖；项目来源已记录在 THIRD_PARTY_NOTICES.md。

- 周课表和日列表跟随手指移动，松开后吸附到相邻页。短距离慢滑会回弹。
- 翻页时轻微淡化和缩放：相邻页最大淡化12%，最大缩小1.5%。不使用旋转。
- 图层直接读取分页偏移，避免为每一帧的动画重新组合整张课表。
- 每次手势最多吸附到相邻一页。周课表边界为本学期第1周至最后一周。
- 日列表可浏览初始日期前后约100年，包含学期之外的日期；周次标题仍按学期边界显示。
- 大字号使网格超宽时，先横向查看网格；同一次手势抵达边缘不会顺带翻周。
  下一次从边缘向外滑动才切换周次。纵向查看课程与点击课程继续可用。
- 上一周／下一周、周次选择、前一天／后一天及回到今天使用分页动画。
- 翻页完成后调用系统轻微触觉反馈；首次显示页面不触发。
- 页面重建保留周次与日列表日期。学期尚未开始时，日列表仍能显示真实今天。

`MainScreens.kt` 管理周次、日期和菜单动作，并按页渲染周网格。
`TimetablePager.kt` 封装分页动画、触觉反馈与放大网格的嵌套滚动保护。
相邻页可能同时存在，因此日期栏测试使用含周次与星期的唯一定位标记。

首次测试发现尚未显示的日分页等待首次布局、导致日模式无法打开，改用
`requestScrollToPage`在显示前请求正确位置。相邻周页面同时保留时，旧测试
通过“星期一”文字定位遇到重复节点，改为具体周次的日期栏定位，保留可见性断言。
最终状态检查补充了学期外“真实今天”的日期保留，以上20项在最终代码上重新通过。
