# van课表本地版本

本版用于本地安装体验。未上传 GitHub，未配置远程仓库、正式签名或在线发布。源码采用 GPL-3.0-only。

## 使用

0.1.11按某学校当前实际网页调整：粘贴 `https://portal.example.edu.cn/kbcx/xskbcx_cxXskbcxIndex.html?gnmkdm=N2151&layout=default`，在应用内登录并进入学生课表查询，选定学年、学期并查询后获取。读取主表，避免重复读取隐藏列表；实践／其它课程保留为无固定时间时段，预览不会显示猜测的钟点。核对教务学期、开学日期与真实作息后保存新课表。详细步骤与验证边界见[适配说明](教务适配说明.md)。

首次打开可以导入文件、从教务获取、手动创建，或查看明确标记的示例课表。示例与真实数据均保存在本机。

“我的 → 课表管理”可保存多份课表，启用其中一份；提醒使用启用的课表；每个桌面小组件可独立绑定一份课表，也可选择跟随启用课表。导入文件经过预览、校验后创建新课表，保留原课表。

0.1.2的“教务导入”不再显示四所学校卡片。输入或粘贴教务系统地址，再点击“打开教务系统”；登录后进入个人课表并点击“获取当前课表”。省略协议时默认使用HTTPS；使用HTTP的校园网入口请完整填写地址。网址中的端口、路径、参数和片段会保留。原有四校适配按网址域名自动匹配，其他网址采用通用网页获取器，不保证所有网页结构都能识别。

也可在此页点击“选择导入文件”，或从导入首页选择本地文件。WakeUp五行备份的作息关联ID不一致时，会按文件内的节次和时间重建关联，在预览中提示核对；不需要手动修改备份ID。多余的作息节次按课表配置的节次数过滤，未补零的时间会规范化。缺节次、重复节次、异常时间、无对应课程和多套作息归属不明时仍停止导入。核对课程、老师、地点、学期和作息后保存。已有启用课表时默认保留当前启用状态，可打开“保存后启用这份课表”；没有启用课表时默认启用导入的新表。

0.1.3可选择PDF、Excel（.xlsx/.xls）或课表图片。Excel读取单元格内容，不执行公式或外部链接；有多个工作表时选择包含个人课表的一张。七列列表可使用“课程名称、星期、开始节数、结束节数、老师、地点、周数”，也支持常见别名和中文周网格。PDF优先读取本机文字层，支持本次提供的三份实际学校导出；扫描文件回退到逐页渲染识别，识别结果合并核对；图片使用本机中英文OCR。均不上传文件，首次使用也不需要下载模型。文件限制25MB（Excel20MB），PDF限制12页。

“识别结果”点击课程展开修改，检查课程数量、星期、开始与结束节次、周次、老师和地点。“查看识别原文”可对照提取出的文字；“补充遗漏课程”和“移除”用于处理漏识别或误识别。缺失或不确定的信息留空，必须补齐有效的星期、节次和周次才能继续。OCR可能识错字，请逐项核对。勾选“已对照原课表核对”后继续，在原导入预览确认开学日期、总周数与真实作息，再保存为新课表。

图片尽量包含完整的星期表头、节次和课程信息。仅拍到一部分课表，或只有某一周日期的截图，无法可靠推断整个学期的安排。不要把当前显示周误当成全部上课周。个人课表可以重新尝试网页获取；如果使用导出的PDF，请选择导出文件，并核对识别结果。

“课表”可左右滑动切换周次；日列表可左右滑动切换日期，并显示星期。放大字号导致网格宽于屏幕时，先横向浏览课程，滚到边缘后继续滑动切周。点击左上角周次选择一周；右上角“…”可切换前后周、回到本周和切换日列表，点击星期也可查看当天。“下一节”用单行提示，点击查看详情。默认根据屏幕空间适配全部节次；标准字号的10节课表可直接查看周一至周日和晚间课程。小屏、大字体或节次较多时保留上下滑动。点击课程可以查看、编辑，按选中日期调整单次课程；冲突时可指定优先显示与提醒的课程，所有冲突课程仍在日列表中保留。课程编辑可增加多个时段，支持间断周、按节次、自定义时间、单次补课和无固定时间的实践课。

“我的 → 学期设置”可修改学期；点击“第1周周一”打开日历，选择实际的第1周周一并保存，周次随新日期重新计算。日历只允许选择周一，避免周次错位。“我的 → 作息管理”可修改节次；作息日期规则决定指定日期采用哪套作息。整日替换读取来源日期的原始课程，不递归复制来源日期上的调课。

“我的 → 节假日设置”给当前课表设置假期名称、开始日期和结束日期，日期均通过日历选择，包含首尾两天。可以编辑或撤销；结束日期不能早于开始日期。0.1.9起，假期内原本安排的课程按“非本周课程”的灰色卡片保留，显示课程名、教室和节次位置并标注“[放假]”，不再给整列涂灰；日列表、自定义时间课程与导出的周图片也显示灰色假期课程供查看。假期预览不受“显示非本周课程”开关影响，可以点击查看原课程。小组件、提醒和下一节计算仍自动跳过假期的普通课、实验课、考试和调入课程。原课程不会删除，撤销假期后恢复。不同课表分别设置假期；重叠假期按日期共同生效，撤销一段不会撤销另一段覆盖的日期。备份包含假期，旧备份没有假期时默认空列表。

“我的 → 外观设置”选择浅色、深色或跟随系统，并设置字号、自动适配整周、节次行高、周末和非本周显示。自动适配开启时设置的行高作为上限，关闭后采用固定行高。学校网站保持其原始网页颜色。

0.1.1修复教务网页老师、地点读取，导入预览显示这两个字段；缺少字段时明确提示数量。此前已保存的空字段没有原网页可恢复，需要在更新后重新获取教务课表，检查预览，再另存并启用。原课表保留，可在确认后自行删除。

“我的 → 桌面小组件”可请求添加今日与明日、今日课程、下一节课程三种组件。系统桌面也可长按添加。小组件采用两行紧凑课程卡片，4×2下今天／明天每列至少显示两节，保留时间和地点；更多课程分别上下滑动。课程名使用常规字重，长课程名和地点显示省略号；今日列表隐藏已经结束的课程。每个实例可设置独立主题和课表；点击小组件底部课表名称即可选择浅色、深色或跟随App，以及显示的课表。0.1.8起，点击组件的课程、日期标题或下一节卡片直接打开该组件绑定的课表，不进入课程详情，也不改变App启用的课表。课程详情中的“添加实验课”“添加期末考试”保留；添加课程可选12种颜色。

保存课表、假期或设置后小组件自动同步，不需要手动点击更新；课程开始／结束及跨天自动刷新，系统还会按30分钟周期更新。在“我的 → 桌面小组件”或组件设置点击“准时刷新授权”，允许“闹钟与提醒”，以便课程时间边界准时刷新。未授权时仍自动更新，但刷新可能延迟；手机的省电与后台限制也可能影响时机。手动刷新按钮保留供临时使用。

“我的 → 提醒与小米手环”开启通知并授权。默认提前10分钟，课程可单独覆盖提前量。没有蓝牙直连；手环通过小米运动健康镜像系统通知，需要在手机上打开该App的通知镜像权限。

备份通过系统文件选择器导出；完整恢复前保存本机快照。单份课表可分享数据或周课表图片。备份不包含密码、登录Cookie或系统授权。

## 构建与目录

模块 `core/domain` 包含课程模型、计算和文件解析；`core/data` 包含Room与DataStore；`app` 包含Compose界面、WebView、小组件、提醒与文件分享。

Java21、Android SDK37.0、Gradle9.3.1。中文Windows目录可运行 `build-local.ps1`，脚本在临时目录建立指向本项目的路径别名，源码仍在原目录。没有删除操作。正式发布前仍需配置用户自己的签名密钥并完成上述真机验证。
