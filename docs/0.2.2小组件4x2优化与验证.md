# van课表 0.2.2：4×2双日小组件

日期：2026-10-12。versionName=0.2.2，versionCode=15。

参考用户提供的 WakeUp 小组件截图调整信息层级。截图作为视觉参考；未导入截图素材，
未复制其他应用代码。验证截图由本应用的真实 Android AppWidgetHost 渲染产生。

## 画面与尺寸

- 默认桌面网格为4列×2行。将旧桌面所用的最小尺寸改为250×110dp，
  避免原170dp最小高度要求额外一行；允许用户在桌面手动调整大小。
- 左上显示课表名，右上显示日期、周次、星期和刷新入口。
  点击课表名打开该组件设置；点日期、课程或空白打开绑定课表。
- 固定今天／明天两列，常规字重的小标题与细分隔线。
  浅色使用灰紫底色，深色保留深灰底色并使用浅色课程文字。
- 有足够高度时，每节课依次显示课程名、教室／教师、时间。
  教师为空时仅显示教室，教室为空时提示地点待定；长名称与地点省略。
- 较矮的4×2桌面使用两行紧凑布局：课程名，时间＋教室。
  当前课程的“上课中”单独标注，减少对课程名的挤占。
- 在最矮尺寸隐藏底部更新时间，将空间留给课程，课表名仍可进入设置。
- 不绘制独立白色课程卡片，不显示粗滚动条；两列仍可分别上下滚动，
  已结束课程、假期过滤及自动刷新保持原逻辑。
- 颜色条保留原有课程颜色和自定义颜色。

系统传入的小组件尺寸已扣除宿主边距。按可用高度选择三行／紧凑布局，
而非直接按外部标称高度选择。API31及以上使用原生RemoteCollectionItems，
旧版本RemoteViewsService同样读取尺寸与独立主题。

时间段不省略、不超出宽度。三行参考场景另检查教师信息、课程文字字重、颜色条和深色文字。

初次尺寸测试发现三行课程在系统边距和中文字体高度叠加后不能完整显示两节，
按可用高度修正布局分档、文字层级和行距。最矮尺寸通过隐藏更新时间保留课程空间。
最终保留文字和卡片的完整可见性断言，未放宽为“有两节课程数据即可”。
原尺寸测试的固定未来时间在夜间可能跨午夜，改为按距离午夜的剩余时间生成不同课程时段，
最终测试未跳过尺寸检查。

本轮未在厂商桌面或API26–30真机上执行；不同桌面的网格尺寸和系统字号可能不同，
