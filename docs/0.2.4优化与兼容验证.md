# 0.2.4 滑动、Excel 与后台入口验证

日期：2026-10-13。版本：0.2.4，versionCode 17。

## 改动

- 每个分页拥有独立的横向 ScrollState，只有已吸附的页面发布横向位置，相邻页同步位置。避免多个网格共享滚动互斥锁和测量状态，并保留放大网格跨周时的位置。
- 缓存周／日课程、冲突分组和时间轴；下一节课程搜索移到后台线程，不随翻页重新搜索。预先加载一页相邻内容，保留手指跟随、18%慢拖阈值、松手吸附和单页滑动限制。
- 新的按钮导航取消上一次导航任务，模式切换也取消未完成的跳转；手势归属不再作为触发界面重组的状态。
- 主 Activity 使用 singleTask。入口处理记录同时包含序号及课程、日期、课表和入口类型；相同入口在页面重建后不重复压入历史，新的外部入口清理旧历史。课程入口使用指定课表查找课程。

实现参考：[Android 官方分页文档](https://developer.android.com/develop/ui/compose/layouts/pager)。

## 用户原始 Excel

文件：本次用户原始 XLSX（仅本机留存），5320字节。复制前后哈希已核对一致；原件名称、哈希和身份信息仅保留在本地验证记录。

解析结果为11门课程、26个时段，未解析内容数为0，所有时段均保留老师及地点。

原件包含同格多门课，以及一门课的多个教学／实践时段。识别按每条明确的时段拆分，合并单元格的整体高度不代替单条时段的节次。课程代码、教学班编号、必选修标签和班级说明不混入课程名称。

重点核对：星期四商务谈判为第6–7节，实训为第6–10节；星期一市场调查拆为4个时段，分别保留9–10周、1–3／6–7／11–16周、8周第9节、8周第10–11节及相应地点。星期日同格的多门课程分别保留；明确的第10–12节不会误读为仅第10节。

原件验证覆盖应用真实读取、识别核对、导入预览、另存启用、页面重建、完整备份及恢复。保存后按课程名、星期、起止节次、周次、老师和地点逐项与读取结果比较。文件选择结果通过测试监视器返回真实原件 URI，后续执行应用真实流程；本轮未声称手动操作系统文件选择器。

文件没有开学日期及每节课钟点。应用保留学期／作息核对步骤；测试为了验证保存与恢复使用临时学期和模板作息，截图中的钟点不是该学校的真实作息。用户保存前必须填写真实数据。原件、原件截图及包含学生姓名、学号的表头不进入公开源码或 APK 资产；通用解析回归使用合成样例。

## 后台与入口

入口回归覆盖课程入口后连续3次页面重建、五次从编辑页进入后台并重新打开课表，以及一次返回离开软件。实际原生小组件课程行点击、绑定课表及切换页签后的复用入口也列入回归。

另外以 ADB `am kill` 在课程详情页进入后台后真实回收应用进程，使用与小组件一致的地址、标记和日期重新进入；验证旧PID消失、新PID出现、主页面只有一个、课表恢复、一次返回到桌面。这里只模拟进程回收，不等同于真机实际放置数小时。

首轮后台脚本曾在应用尚未完成恢复时读取到旧快照或空UI树，已改为等待稳定课表节点。测试框架入口标识与Activity重建不匹配的问题也已修正。保留最终结果，并不把这些脚本失败当成应用通过的证据。

## 验证与性能

测试设备：emulator-5556，Android API37，360×800，160dpi；应用Debug构建。使用 Android Emulator QA 与 Android Performance 技能进行实际验证。

最终交付APK的17项Android回归全部通过，110.297秒，0失败、0跳过。涵盖4项本次专项（含性能采集）、6项分页回归、1项放大网格、1项实际小组件入口、4项Excel读取、1项Excel核对界面测试。三轮真实后台回收也全部通过；崩溃缓冲区为空。构建成功，lint为0错误、72条既有警告。

最终单元检查共72项：71通过、0失败、1项可选旧PDF原件对照因未提供该参数而跳过。本次新增2项Excel网格格式回归均通过。原始Excel的实际流程没有跳过。

性能流程使用固定的35门课程、35个时段、20周课表；每版本预热4组双向翻页，再记录3轮，每轮8组双向滑动，共16次滑动。布局、字号、主题及触摸坐标一致；每次检查周次确实切换。性能测试使用合成固定课表，和原始Excel兼容测试分别记录。
