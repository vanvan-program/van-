# 河北建筑工程学院课表适配

适配版本：0.1.11-local。入口为 [学生课表查询](https://jwx.hebiace.edu.cn/kbcx/xskbcx_cxXskbcxIndex.html?gnmkdm=N2151&layout=default)。本次依据2026-10-12内置浏览器中已登录的实际页面调整。

## 使用

1. 安装新版，在“导入课表 → 从教务系统获取”粘贴上述网址。
2. 在应用内登录教务系统，进入“学生课表查询”。选择学年、学期并点击查询。
3. 点击“获取当前课表”。在导入预览核对课程、老师、教室、星期、节次、周次以及显示的教务学期。
4. 确认第1周周一、总周数和真实作息，再保存为新课表。旧课表保留。

优先读取已经查询完成的主表，不重复解析同一页面挂载的隐藏列表。当前2026-2027学年第1学期页面包含26个常规时段，以及底部3项实践课程和6项其它课程；新版保留全部35个时段。支持同格多课程、图标旁的老师和教室、间断周、单双周和“【调】”课程名。

底部9项课程保留名称、教师和周次，按“无固定上课时间”保存；没有明确地点时显示“未安排”。不猜星期、节次或具体钟点，不将它们排入周课表节次，也不安排上课提醒。作息仍需自行核对，默认时间不是学校官方作息。

所选学期与已经显示的表格标题不一致时，提示先点击查询。坏字段或无法识别的页脚条目会整体停止导入。没有已查询主表时仍尝试同源接口与通用DOM回退；接口里无法完整解析的实践课程继续提示改用PDF／Excel，不只保存部分常规课程。

## 实现依据与验证边界

2026-10-11只读访问入口时跳转到 `/xtgl/login_slogin.html`。2026-10-12通过用户当前内置浏览器的已登录页面读取课表结构，确认主表 `kbgrid_table_0`、隐藏列表 `kblist_table`、页脚“实践课程／其它课程”和所选学期值。未获取或转移登录Cookie，没有重新请求个人课表接口。测试重建样本移除了学生身份、教学班编号，并使用教师代称。

专用脚本 `app/src/main/assets/adapters/hebiace.js` 独立实现正方学生课表查询协议。查询路径和字段参考协议实现者的[公开源文件](https://github.com/openschoolcn/zfn_api/blob/main/zfn_api.py)：`kbcx/xskbcx_cxXsKb.html?gnmkdm=N2151`，学期参数 `xnm`、`xqm`，课程集合 `kbList`，课程字段 `kcmc`、`xqj`、`jc`、`zcd`、`xm`、`cdmc`。这份资料用于确认通用协议，不能代替本校登录后的真实响应。脚本按页面所选值请求，不按月份猜学期，不传入其他学生的标识。

请求仅发送到当前页面的同源教务接口，使用已有登录会话。导入结果只包含课程与学期标签，不包含账号、密码、Cookie或学生档案。

在模拟器中打开本校真实登录页时，发现页面把数组的 `filter`、`some` 回调改成先传下标，且改写了 `every`。专用获取器与通用DOM回退现在使用自身的筛选和判断方法，避免获取报错、学期标签缺失或实践课漏检；不会修改网站的数组方法。新增合成测试复现了这些行为。

验证包括按实际页面重建的26个常规时段和9个页脚条目，以及既有合成接口回归。覆盖隐藏列表隔离、同格多课程、混合单双周、未查询学期拦截、无固定时间保存与预览、异常页脚拒绝及备份。实际运行结果见[本地验证报告](本地验证报告.md)。

当前页面的学期、课程数量和字段结构已对照；学校官方作息、第1周周一，以及其它学期或站点更新后的结构仍需核对。
