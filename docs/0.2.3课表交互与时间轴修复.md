# 0.2.3 课表交互与时间轴修复

日期：2026-10-13。版本：0.2.3（versionCode 16）。

## 本次行为

### 独立返回按钮

“课表”右侧增加独立的竖排“回到本周”按钮；在日视图中显示“回到今日”。按钮所在边栏宽 44dp，只有浏览的周次或日期离开当前周次或今日时才出现。按钮使用固定边栏，课程区域不会被覆盖，按钮出现和消失也不会改变课表宽度。

### 周次滑动

慢速拖动切换周次的距离阈值从页面宽度的 50% 降为 18%。页面继续跟随手指移动，松手后吸附到目标周次；一次滑动最多切换一页。已有放大课表的内部横向滚动保护保持有效。

### 说明区域

周次下方的调课或特殊安排说明固定预留 `20dp × fontScale` 的高度。说明显示为单行，较长内容通过 marquee 滚动显示。没有说明的周次仍保留相同高度，切换周次时课表区域不会因为说明的有无突然伸缩。

### 自定义时间轴

时间轴继续使用课表内的原始作息。`GridTimeline` 只为 CLOCK 课程或修改时间后的课程实际占用的课间增加空间，重叠区间合并；未被课程占用的课间保持压缩。

例如课程从 10:20 开始，原作息第 3 节从 10:30 开始，新增时间段显示 10:20–10:30；此前错误地将整个 09:50–10:30 课间展开。额外时间文本使用 11sp 行高，避免短时间行的文字被裁切。
